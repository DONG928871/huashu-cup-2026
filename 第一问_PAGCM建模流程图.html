开始：读取附件三维粒子坐标数据

1
场景抽象：三维粒子 → 图节点映射
每颗导电填料粒子 → 图节点 V；粒子间接触/近邻关系 → 边 E
RVE 周期边界 → 环面拓扑约束
2
变量定义：节点属性和边权函数
节点属性：坐标 pᵢ = (xᵢ, yᵢ, zᵢ)，等效半径 rᵢ
边权函数：dₜ(pᵢ, pⱼ) = min ‖pᵢ − pⱼ + kL‖（环面距离）
模 型 构 建
3
KD-Tree 空间索引构建
3D KD-Tree 分区
O(N log N) 近邻检索加速
替代全局 O(N²) 距离计算
4
自适应距离阈值计算
密度感知等效半径：
rᵉᶠᶠ = r₀ · (1 + α · ρ_local/ρ̄)
sparse → 放宽，dense → 收紧
5
周期边界拓扑嵌入：跨边界边生成
对距边界 < rᵉᶠᶠ 的粒子，在周期方向构建跨边界虚拟边
边标签存储周期偏移矢量 k ∈ ℤ³，实现环面上的图结构
求 解 迭 代
6
并查集聚类：周期感知的连通分量识别
Union-Find + 路径压缩 + 按秩合并
连接判据：环面距离 dₜ(pᵢ, pⱼ) ≤ rᵢᵉᶠᶠ + rⱼᵉᶠᶠ
自动合并跨周期边界的等价类
7
方向性连通判定：贯穿边界检测
X / Y / Z 方向分别判定：是否存在一个连通分量
同时包含「源边界粒子集」和「目标边界粒子集」？
Find(源粒子) = Find(目标粒子) → 该方向连通 ✓
结 果 验 证
8
结果验证与敏感性分析
① 与 GPNM 暴力枚举交叉验证 ② 蒙特卡洛位置扰动（±δ）→ 连通概率
③ 参数 α 扫描 → 稳定性评估 ④ 连通分量演化曲线 vs 填充率
✓
输出：各方向连通性判定 + 最短导通路径 + 最大簇统计
二值结果（通 / 断）+ 可视化的逾渗路径粒子链 + 连通分量分布
